<objective>
Turn the Wave-0 static gradient layer into the full reactive effect:

- D-04/D-05: on fine-pointer devices, a `pointermove` listener stores a normalised
  target; a `requestAnimationFrame` loop lerps toward it (damped parallax, factor
  ~0.06) and writes `--mx`/`--my` to the layer via `el.style.setProperty()` — no
  React state per frame, zero re-renders.
- D-06/D-07: on no-fine-pointer / touch devices, a `.gradient-bg--breathing` class
  runs a slow opacity pulse using `var(--dur-breath)` (added in Plan 02).
- D-08: `matchMedia('(pointer: fine)')` decides the mode, with a `change` listener so
  hybrid devices switch live.
- D-09: `prefersReducedMotion()` gates the JS (no listener, no rAF) and the DLS global
  CSS reset kills the breathing keyframe — the gradient is static and centred.

Purpose: Deliver the reactive behaviour on top of the already-tested layer.
Output: full `GradientBackground.tsx` effects, the `.gradient-bg--breathing` +
`@keyframes gradient-breathe` CSS, and a project-branched breathing-class test.
</objective>

Effect B — pointer rAF loop (RESEARCH.md verified pattern; reduced-motion + coarse-pointer gates):
```tsx
useEffect(() => {
  if (prefersReducedMotion()) return;          // D-09 JS gate — no listener, no loop
  if (!isFinePointer) return;                   // D-08 — breathing handled by CSS class
  const el = layerRef.current;
  if (!el) return;

  const target = { x: 0.5, y: 0.5 };
  const current = { x: 0.5, y: 0.5 };
  let frameId = 0;
  const lerp = (a: number, b: number, t: number) => a + (b - a) * t;
  const FACTOR = 0.06;                          // damped parallax (D-04); keep <= 0.08 (paint cost)

  const onPointerMove = (e: PointerEvent) => {
    target.x = e.clientX / window.innerWidth;
    target.y = e.clientY / window.innerHeight;
  };
  const tick = () => {
    current.x = lerp(current.x, target.x, FACTOR);
    current.y = lerp(current.y, target.y, FACTOR);
    el.style.setProperty("--mx", `${(current.x * 100).toFixed(2)}%`);
    el.style.setProperty("--my", `${(current.y * 100).toFixed(2)}%`);
    frameId = requestAnimationFrame(tick);
  };
  window.addEventListener("pointermove", onPointerMove, { passive: true });
  frameId = requestAnimationFrame(tick);
  return () => {
    window.removeEventListener("pointermove", onPointerMove);
    cancelAnimationFrame(frameId);
  };
}, [isFinePointer]);
```
